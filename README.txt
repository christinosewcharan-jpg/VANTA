# VANTA website preview

## Open it locally in Chrome
1. Extract the ZIP file.
2. Open the `vanta-website` folder.
3. Double-click `index.html`.
4. It opens in your browser. This is a local preview, not a public website.

## Current status
This is a front-end preview. Ticket selection and price totals work.
It does NOT yet process payments, reserve inventory, issue QR tickets, or send emails.
Those require a secure backend, database, payment-gateway approval, and webhook verification.
